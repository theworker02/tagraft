# tagraft

Tag digests and raft fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/tagraft/

## Install / run

```bash
git clone https://github.com/theworker02/tagraft.git
cd tagraft
node src/cli.js
node --test
```
